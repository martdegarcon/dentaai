# DentAI — лендинг электрической зубной щётки с ИИ

Дизайн-концепт лендинга из двух блоков (тестовое задание). Концепт — «Прозрачная технология»: щётка открывается, когда пользователь в неё заглядывает.

**Демо:** после включения GitHub Pages — `https://<username>.github.io/<repo>/`

## Что на странице

**Блок 1 — первый экран.** Белая щётка. При наведении за курсором едет «лупа», внутри которой корпус прозрачный и видна начинка. При прокрутке щётка раскладывается на 6 деталей с подписями.

**Блок 2 — «Технологии».** Горизонтальный проход вдоль разобранной щётки от насадки до торца. У нужных деталей появляются карточки:
1. 3D-модель полости рта — схема челюсти с подсвеченными зонами.
2. ИИ-анализ движений — концентрические орбиты, точка описывает круговое движение.
3. Подключение к приложению — кольцо из радиальных штрихов, заполняется по неделе.
4. Геймификация — «+20» и расходящиеся круги.

Автотур для записи видео: открыть страницу с `#tour` в конце адреса. Любое действие пользователя останавливает тур.

## Структура

```
index.html            вся страница: разметка, стили, скрипт
assets/
  parts/              6 деталей щётки для первого экрана: *-white (корпус) и *-xray (рентген)
  xray/               детали щётки в полном разрешении для блока «Технологии»
  brush/              щётка целиком без фона: белая и рентген (2172×724, совпадают пиксель в пиксель)
  icons/              иконки (SVG)
.nojekyll             чтобы GitHub Pages отдавал файлы как есть
```

Сборка не нужна: это статичная страница без зависимостей. Шрифт Onest подгружается с Google Fonts.

## Запуск локально

Открыть `index.html` в браузере. Или поднять сервер в папке проекта:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "DentAI landing concept"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**. Через минуту страница будет доступна по адресу `https://<username>.github.io/<repo>/`.

- Шрифт: Onest. H1 60/63, H2 56, заголовок карточки 28, текст 15–19.
